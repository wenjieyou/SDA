# SDA
Selective Data Augmentation for Few-Shot Protein Function Prediction

## Usage

The workflow consists of three steps:

1. **Full Data Augmentation (FDA):** Run `fda_data_augmentation.py` to generate the full augmented dataset.
2. **Selective Data Augmentation (SDA):** Run `sda_data_augmentation.py` to generate a selectively augmented dataset. The augmentation size \(K\) can be specified; by default, it matches the number of augmented samples generated by FDA.
3. **CNN Classification and Evaluation:** Use the augmented dataset as input to a CNN classifier and evaluate its performance using one of the following scripts:

   * `cnn_20x20_holdout.py` — hold-out evaluation.
   * `cnn_20x20_kfold_cv.py` — K-fold cross-validation.
   * `cnn_20x20_loocv.py` — leave-one-out cross-validation (LOOCV).

The evaluation scripts report the corresponding classification performance metrics.
